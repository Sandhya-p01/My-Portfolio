# Sandhya Pogula — Data Analyst Portfolio

This version is deliberately built as a **single-file website**. All CSS and JavaScript are embedded inside `index.html`, so it will not appear unstyled when opened locally.

## Open it

1. Extract the ZIP completely.
2. Open the extracted `sandhya-portfolio` folder.
3. Double-click `index.html`.

Do not open `index.html` from inside the ZIP preview.

## Replace placeholder links

Open `index.html` in Notepad or VS Code and search for `class="placeholder"`. Replace `href="#"` with your real:

- LinkedIn URL
- GitHub URL
- Project repository URL
- Resume PDF path or public link

The email address is already added as `sandhyapogula1@gmail.com`.

## Publish on GitHub Pages

Upload `index.html` to the root of a GitHub repository, then enable GitHub Pages from repository Settings → Pages.
